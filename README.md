# OpenMP задания

Проект содержит решения заданий по OpenMP. В каждой папке есть последовательная программа, параллельный вариант с `reduction`, вариант без `reduction` и программа для экспериментов.

## Структура

- `task1` — поиск максимального элемента вектора
- `task2` — скалярное произведение двух векторов
- `task3` — вычисление интеграла методом прямоугольников
- `task4` — максимум среди минимумов строк матрицы
- `.vscode` — настройки сборки и запуска

## Запуск через VS Code

1. Откройте папку проекта `D:\projects\openmp` в VS Code.
2. Откройте **Run and Debug** через `Ctrl+Shift+D`.
3. Выберите конфигурацию нужного задания, например `Запустить задание 2 во встроенном терминале`.
4. Нажмите `F5`.

Перед запуском программы автоматически пересобираются с поддержкой OpenMP.

Для получения таблицы экспериментов выберите конфигурацию `Запустить эксперименты задания N`. Результаты сохраняются в `taskN/results.csv`.

Для сборки без запуска можно использовать `Ctrl+Shift+B` и выбрать задачу сборки нужного задания.

## Требования

- VS Code
- MSYS2 MinGW-w64
- компилятор `g++` с поддержкой OpenMP
